# Stanford Bunny attribution

Source: **Stanford University Computer Graphics Laboratory**, [The Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/).

Archive: https://graphics.stanford.edu/pub/3Dscanrep/bunny.tar.gz

Included model: `bunny/reconstruction/bun_zipper_res4.ply`, the repository's reduced-resolution Bunny (453 vertices, 948 triangles).

The model is stored in `js/mesh-data.js` for offline use. Coordinates were centered and uniformly scaled for display, and unused-vertex removal was applied (the vertex count remained 453). Original triangle connectivity was retained. No cotangent or continuous-surface approximation is claimed.

Data source checked: 2026-09-08.

The torus, sphere, and grid are generated locally by this project's code and do not use third-party mesh data.
